# Подбор методов UX-исследований

Веб-приложение для подбора методов UX-исследований на основе параметров проекта: этапа продукта, целей исследования, типа данных, доступности пользователей и ресурсов.

Приложение реализует модель рекомендаций и помогает выбрать наиболее релевантные методы с объяснением причин выбора.

---

## Назначение

Сервис предназначен для:
- выбора подходящих методов UX-исследований
- понимания различий между методами
- формирования обоснованных решений при планировании исследований

В отличие от простых справочников, система:
- учитывает контекст задачи
- ранжирует методы
- объясняет, почему они были выбраны

---

## Как работает логика

Пользователь задаёт параметры исследования:

- этап продукта (концепция / разработка / готовый)
- цель (проблемы / поведение / мнение / сравнение)
- тип данных (качественные / количественные / смешанные)
- доступ к пользователям (есть / нет)
- ресурсы (низкие / средние / высокие)
- условия (лабораторно / в реальной среде)

На основе этих параметров система:

1. Фильтрует неподходящие методы  
2. Рассчитывает релевантность методов (scoring)  
3. Формирует:
   - Top-3 методов
   - дополнительные методы
   - объяснение выбора
